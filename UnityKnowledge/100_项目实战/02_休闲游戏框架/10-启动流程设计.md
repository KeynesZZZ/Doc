# 启动流程设计

> 海外休闲游戏完整启动链路：AOT 基础设施初始化 → HybridCLR 加载热更 DLL → 热更代码接管框架初始化 → 后台静默热更。核心原则：离线优先，无网也能进游戏。

## 文档定位

- **资源管理**：[[03-资源管理设计]] 已覆盖 YooAsset 架构
- **热更系统**：[[05-热更系统设计]] 已覆盖静默热更策略
- **本文**：聚焦完整启动链路的初始化顺序和代码实现

### 关键设计决策

| 决策 | 说明 |
|------|------|
| **Phase 0 极简** | AOT 层只做最小化初始化，尽快转交热更代码 |
| **Phase 1 不等网络** | 用本地资源立即进入游戏 |
| **Phase 2 并行** | 热更检查与游戏并行，互不干扰 |
| **Loading 最小化** | 只在 Phase 0 短暂 Loading，Phase 1 几乎无感 |

## 二、Phase 0: AOT 层启动

### 2.1 Bootstrap 场景

- 场景中只有一个 GameObject，挂载 `GameBootstrap` 脚本
- 包含一个简单的 Loading UI（Logo / 进度条）
- 此场景的资源和脚本**不可热更**

### 2.2 GameBootstrap 完整实现

```csharp
using System;
using System.Linq;
using System.Reflection;
using UnityEngine;
using YooAsset;
using HybridCLR;
using Cysharp.Threading.Tasks;

/// <summary>
/// AOT 层启动入口 — 唯一挂在 Bootstrap 场景的 MonoBehaviour
/// 职责：初始化基础设施 → 加载热更 DLL → 转交控制权给热更代码
/// </summary>
public class GameBootstrap : MonoBehaviour
{
    [SerializeField] private GameObject _loadingCanvas;

    private ResourcePackage _package;

    private async UniTaskVoid Start()
    {
        try
        {
            DontDestroyOnLoad(_loadingCanvas);
            _loadingCanvas.SetActive(true);

            Debug.Log("=== Phase 0: AOT 启动 ===");

            // 0c. YooAsset 初始化
            await InitYooAsset();

            // 0d. 加载 AOT 元数据
            await LoadAOTMetadata();

            // 0e. 加载 HotUpdate.dll
            Assembly hotUpdateAsm = await LoadHotUpdateDLL();

            // 0f. 转交控制权
            InvokeHotUpdateEntry(hotUpdateAsm);
        }
        catch (Exception e)
        {
            Debug.LogError($"[Bootstrap] 启动失败: {e}");
            // 显示错误提示，提供重试按钮
            ShowFatalError(e.Message);
        }
    }

    /// <summary>
    /// 0c. YooAsset 初始化 — HostPlayMode（Buildin + Cache + Remote）
    /// 即使无网，Buildin 层也能提供完整游戏体验
    /// </summary>
    private async UniTask InitYooAsset()
    {
        YooAssets.Initialize();
        _package = YooAssets.CreatePackage("DefaultPackage");
        YooAssets.SetDefaultPackage(_package);

        var param = new HostPlayModeParameters
        {
            BuildinFileSystemParameters =
                FileSystemParameters.CreateDefaultBuildinFileSystemParameters(),
            CacheFileSystemParameters =
                FileSystemParameters.CreateDefaultCacheFileSystemParameters(),
            RemoteServices = new GameRemoteServices()
        };

        var op = _package.InitializeAsync(param);
        await op.ToUniTask();

        if (op.Status != EOperationStatus.Succeed)
        {
            // 初始化失败，清理 Cache 回退到 Buildin
            Debug.LogWarning("[Bootstrap] YooAsset 初始化失败，尝试回退到内置资源");
            await _package.ClearAllBundleFilesAsync();

            var retryParam = new HostPlayModeParameters
            {
                BuildinFileSystemParameters =
                    FileSystemParameters.CreateDefaultBuildinFileSystemParameters(),
                CacheFileSystemParameters =
                    FileSystemParameters.CreateDefaultCacheFileSystemParameters(),
            };
            await _package.InitializeAsync(retryParam).ToUniTask();
        }

        Debug.Log("[Bootstrap] YooAsset 初始化完成");
    }

    /// <summary>
    /// 0d. 加载 HybridCLR AOT 元数据
    /// </summary>
    private async UniTask LoadAOTMetadata()
    {
        string[] aotDlls =
        {
            "mscorlib.dll",
            "System.dll",
            "System.Core.dll",
            "UnityEngine.CoreModule.dll",
            "Unity.Collections.dll",
            "UnityEngine.UI.dll"
        };

        foreach (var dllName in aotDlls)
        {
            var handle = _package.LoadAssetAsync<TextAsset>($"AOT_{dllName}");
            await handle.ToUniTask();

            if (handle.Status == EOperationStatus.Succeed)
            {
                int err = RuntimeApi.LoadMetadataForAOTAssembly(
                    (handle.AssetObject as TextAsset).bytes,
                    HomologousImageMode.SuperSet
                );
                if (err != 0)
                    Debug.LogWarning($"[Bootstrap] AOT 元数据加载警告: {dllName}, code={err}");
            }
            else
            {
                Debug.LogWarning($"[Bootstrap] AOT 元数据缺失: {dllName}");
            }
            handle.Release();
        }

        Debug.Log("[Bootstrap] AOT 元数据加载完成");
    }

    /// <summary>
    /// 0e. 加载热更 DLL
    /// </summary>
    private async UniTask<Assembly> LoadHotUpdateDLL()
    {
        var handle = _package.LoadAssetAsync<TextAsset>("HotUpdate.dll");
        await handle.ToUniTask();

        if (handle.Status != EOperationStatus.Succeed)
        {
            throw new Exception("HotUpdate.dll 加载失败，无法启动游戏");
        }

        byte[] dllBytes = (handle.AssetObject as TextAsset).bytes;
        var assembly = Assembly.Load(dllBytes);
        handle.Release();

        Debug.Log($"[Bootstrap] HotUpdate.dll 加载完成: {assembly.GetName().Version}");
        return assembly;
    }

    /// <summary>
    /// 0f. 反射调用热更代码入口
    /// </summary>
    private void InvokeHotUpdateEntry(Assembly assembly)
    {
        var entryType = assembly.GetType("HotUpdate.GameEntry");
        if (entryType == null)
            throw new Exception("HotUpdate.GameEntry 类型未找到");

        var startMethod = entryType.GetMethod("Start", BindingFlags.Public | BindingFlags.Static);
        if (startMethod == null)
            throw new Exception("HotUpdate.GameEntry.Start() 方法未找到");

        // 传递 AOT 层的 Bootstrap 引用，让热更代码可以控制 Loading UI
        var args = new object[] { _loadingCanvas };
        startMethod.Invoke(null, args);

        Debug.Log("[Bootstrap] 控制权已转交 HotUpdate");
    }

    private void ShowFatalError(string message)
    {
        // 简单的错误 UI：文本 + 重试按钮
        Debug.LogError($"致命错误: {message}");
    }
}
```

## 三、Phase 1: 热更层接管

### 3.1 GameEntry（热更代码入口）

```csharp
using UnityEngine;
using UnityEngine.UI;
using Cysharp.Threading.Tasks;
using YooAsset;

namespace HotUpdate
{
    /// <summary>
    /// 热更代码入口 — 在 HotUpdate.dll 中
    /// 接收 AOT 层转交的控制权，初始化框架核心
    /// </summary>
    public static class GameEntry
    {
        /// <summary>
        /// AOT 层通过反射调用此方法
        /// </summary>
        public static async void Start(GameObject loadingCanvas)
        {
            Debug.Log("=== Phase 1: 热更层接管 ===");

            // 1a. 初始化框架核心（按依赖顺序）
            var package = YooAssets.GetPackage("DefaultPackage");
            var assetMgr = new AssetManager(package);

            // 基础设施
            var eventBus = new EventBus();
            var uiManager = new UIManager(assetMgr, eventBus);
            var configMgr = new ConfigManager();
            var audioMgr = new AudioManager(assetMgr);
            var saveMgr = new SaveManager();
            var objectPool = new ObjectPoolManager(assetMgr);

            // 1b. 加载配置表
            await configMgr.LoadAllConfigsAsync(assetMgr);

            // 1c. 加载本地存档
            saveMgr.LoadLocalSave();

            // 注册全局单例
            GameContext.Init(assetMgr, eventBus, uiManager, configMgr,
                             audioMgr, saveMgr, objectPool);

            Debug.Log("[GameEntry] 框架核心初始化完成");

            // 1d. 进入主场景
            await EnterMainScene(loadingCanvas);

            // 启动后台静默热更（Phase 2）
            var hotUpdateMgr = new HotUpdateManager(package, GetVersionConfigUrl());
            hotUpdateMgr.RunSilentUpdate().Forget();

            Debug.Log("=== 启动完成，进入游戏 ===");
        }

        /// <summary>
        /// 进入主场景
        /// </summary>
        private static async UniTask EnterMainScene(GameObject loadingCanvas)
        {
            // 异步加载主场景
            var package = YooAssets.GetPackage("DefaultPackage");
            var sceneHandle = package.LoadSceneAsync("MainScene");
            await sceneHandle.ToUniTask();

            // 隐藏 AOT 层的 Loading
            loadingCanvas.SetActive(false);
            Object.Destroy(loadingCanvas, 1f);
        }

        private static string GetVersionConfigUrl()
        {
            // 根据 platform + region 拼接
            return "https://global-cdn.yourgame.com/version_config.json";
        }
    }
}
```

### 3.2 GameContext（全局上下文）

```csharp
namespace HotUpdate
{
    /// <summary>
    /// 全局游戏上下文 — 框架核心管理器的统一入口
    /// </summary>
    public static class GameContext
    {
        public static AssetManager Asset { get; private set; }
        public static EventBus Event { get; private set; }
        public static UIManager UI { get; private set; }
        public static ConfigManager Config { get; private set; }
        public static AudioManager Audio { get; private set; }
        public static SaveManager Save { get; private set; }
        public static ObjectPoolManager Pool { get; private set; }

        public static void Init(
            AssetManager asset, EventBus eventBus, UIManager ui,
            ConfigManager config, AudioManager audio, SaveManager save,
            ObjectPoolManager pool)
        {
            Asset = asset;
            Event = eventBus;
            UI = ui;
            Config = config;
            Audio = audio;
            Save = save;
            Pool = pool;
        }

        public static void Dispose()
        {
            Asset?.ReleaseAll();
            UI?.Clear();
            Save?.SaveAll();
        }
    }
}
```

## 四、初始化顺序详解

### 4.1 为什么是这个顺序？

```
YooAsset → AOT 元数据 → HotUpdate.dll → 框架核心 → 配置 → 存档 → 场景
```

| 步骤 | 依赖 | 说明 |
|------|------|------|
| YooAsset | 无 | 基础设施，所有后续步骤都依赖它 |
| AOT 元数据 | YooAsset | 需要从 YooAsset 加载 DLL 的 TextAsset |
| HotUpdate.dll | AOT 元数据 | 元数据必须先加载，否则泛型会崩 |
| EventBus | 无 | 框架通信基础 |
| UIManager | Asset + Event | UI 加载依赖资源管理器 |
| ConfigManager | Asset | 配置表从 YooAsset 加载 |
| AudioManager | Asset | 音频资源从 YooAsset 加载 |
| SaveManager | 无 | 纯本地操作 |
| 场景加载 | 所有管理器 | 主场景中的组件可能依赖所有管理器 |

### 4.2 关键约束

```csharp
// ✅ 正确：YooAsset 先于 HybridCLR
await InitYooAsset();
await LoadAOTMetadata();
await LoadHotUpdateDLL();

// ❌ 错误：先加载 DLL 再初始化 YooAsset
// DLL 的 TextAsset 从哪里加载？Resources？
// 如果用 Resources，DLL 无法热更！
await LoadHotUpdateDLL();  // ← 找不到 DLL
await InitYooAsset();

// ❌ 错误：先加载 HotUpdate.dll 再加载 AOT 元数据
// HotUpdate.dll 中的泛型方法调用会直接崩溃
await LoadHotUpdateDLL();
var list = new List<int>();  // 💥 崩溃！缺少 mscorlib 元数据
await LoadAOTMetadata();
```

## 五、Loading 体验优化

### 5.1 分阶段 Loading 展示

```csharp
// Bootstrap 阶段（AOT 层）的 Loading 文案
private static readonly string[] LoadingTips =
{
    "正在准备游戏...",      // 0c. YooAsset 初始化
    "正在加载运行时...",    // 0d. AOT 元数据
    "正在加载游戏代码...",  // 0e. HotUpdate.dll
    "正在初始化...",        // 1a. 框架核心
    "正在加载配置...",      // 1b. 配置表
    "即将开始..."           // 1d. 场景加载
};

// 配合 Loading 进度条
loadingSlider.value = (float)phase / TotalPhases;
loadingText.text = LoadingTips[phase];
```

### 5.2 启动耗时目标

| 阶段 | 中端 Android 目标 | 说明 |
|------|-------------------|------|
| Phase 0 全部 | < 2 秒 | AOT 初始化 |
| Phase 1 全部 | < 1 秒 | 框架初始化 |
| 场景加载 | < 1 秒 | 首包资源 |
| **总启动** | **< 4 秒** | 从点击到可操作 |

> 首次安装启动可能稍慢（无 Cache），后续启动有 Cache 后更快。

## 六、AOT/热更代码分离规范

```
Assets/
├── Game/                          ← AOT 层（不可热更）
│   └── Scripts/
│       ├── Bootstrap/
│       │   └── GameBootstrap.cs   ← 启动入口
│       └── Shared/
│           ├── Interfaces/         ← 热更代码可能用到的接口定义
│           └── Structs/            ← 共享的数据结构
│
└── HotUpdate/                     ← 热更层（可热更）
    └── Scripts/
        ├── Core/                  ← 框架核心（可热更）
        │   ├── AssetManager.cs
        │   ├── UIManager.cs
        │   ├── EventBus.cs
        │   └── ...
        ├── GameEntry.cs           ← 热更入口
        ├── Game/                  ← 游戏逻辑
        └── UI/                    ← UI 逻辑
```

### 分离原则

| AOT 层（Game/） | 热更层（HotUpdate/） |
|-----------------|---------------------|
| GameBootstrap | GameEntry |
| YooAsset SDK 调用 | AssetManager 封装 |
| HybridCLR 加载 | 所有业务逻辑 |
| 接口/结构体定义 | 所有 UI 逻辑 |
| 第三方 SDK 原生桥接 | 所有游戏系统 |

**规则**：AOT 层代码尽量少，只做基础设施初始化。所有业务逻辑和框架核心都放热更层。

## 七、异常恢复

### 7.1 启动失败处理

```csharp
/// <summary>
/// 全局异常恢复策略
/// </summary>
private async UniTaskVoid HandleStartupError(Exception e)
{
    Debug.LogError($"[Bootstrap] 启动异常: {e}");

    if (e is InvalidOperationException)
    {
        // YooAsset 初始化失败
        // 尝试清理 Cache 重试
        await _package.ClearAllBundleFilesAsync();
        ShowRetryDialog("资源初始化失败，请重试");
    }
    else if (e.Message.Contains("HotUpdate"))
    {
        // DLL 加载失败 — 严重错误
        ShowRetryDialog("游戏文件损坏，请重新安装");
    }
    else
    {
        ShowRetryDialog("启动失败，请重试");
    }
}
```

### 7.2 重试机制

```csharp
private int _retryCount = 0;
private const int MaxRetry = 2;

public async UniTaskVoid RetryStartup()
{
    if (_retryCount >= MaxRetry)
    {
        ShowFatalError("多次启动失败，请联系客服");
        return;
    }
    _retryCount++;

    // 重新执行启动流程
    await Start().ToUniTask();
}
```
