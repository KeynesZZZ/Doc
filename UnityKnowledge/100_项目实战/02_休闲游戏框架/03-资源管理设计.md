# 资源管理设计

> 海外休闲单机游戏的资源管理方案：离线优先、首包自足、静默热更。基于 YooAsset HostPlayMode 三层架构（Buildin + Cache + Remote）。

## 文档定位

休闲游戏框架的资源管理层设计，聚焦海外单机休闲游戏的特殊需求：弱网/无网可玩、包体小、资源迭代快。

- **YooAsset 基础概念**：[[../../35_高级主题/【笔记】YooAsset核心概念与架构]] 已覆盖
- **打包管线**：[[../../35_高级主题/【笔记】YooAsset打包管线与分包策略]] 已覆盖
- **本文**：聚焦离线优先的资源架构设计和 AssetManager 封装

---

## 一、核心设计原则

| 原则 | 说明 |
|------|------|
| **离线优先** | 无网络时首包资源必须能支撑完整游戏体验 |
| **热更不阻断** | 热更检查后台静默进行，不阻塞游戏启动 |
| **首包自足** | 核心玩法资源全部内置，不依赖下载 |
| **引用计数** | 统一的 Load/Release 配对管理，防泄漏 |

## 二、三层资源架构

```
┌──────────────────────────────────────────────────────────┐
│                    首包 (APK / AAB)                        │
│                                                          │
│  L0: 核心层（离线可玩的最小集）                            │
│  ├── StreamingAssets/                                    │
│  │   └── DefaultPackage/  ← YooAsset Buildin 层          │
│  │       ├── manifest.bytes                              │
│  │       └── bundles/                                    │
│  │           ├── 启动场景 / 主菜单                         │
│  │           ├── 核心玩法场景（前 20 关）                   │
│  │           ├── 基础 UI 框架                              │
│  │           ├── 核心角色 / 道具                           │
│  │           ├── 基础音效 / BGM                            │
│  │           └── HotUpdate.dll + AOT 元数据               │
│  │                                                       │
│  体积控制: 30-80MB                                         │
├──────────────────────────────────────────────────────────┤
│                  Cache 层（热更下载）                      │
│                                                          │
│  L1: 增量层（热更补丁）                                    │
│  ├── persistentDataPath/DefaultPackage/                  │
│  │   └── bundles/                                        │
│  │       ├── Bug 修复后的 Prefab / 配置                   │
│  │       ├── 新关卡资源（21+ 关）                          │
│  │       ├── 活动 / 节日资源                               │
│  │       └── 新 DLL 版本                                  │
│  │                                                       │
│  优先级: Cache > Buildin（热更资源覆盖内置）                │
└──────────────────────────────────────────────────────────┘
```

**关键**：YooAsset 的 HostPlayMode 天然支持这种分层。加载资源时先查 Cache 层（热更后），没有再回退到 Buildin 层（首包内置）。

## 三、Collector 分组配置

休闲游戏包体小，**用单 Package + 多 Collector Group** 即可，不需要多 Package 分包。

| Group | Collect Path | Address Rule | Pack Rule | 进入首包 | 说明 |
|-------|-------------|--------------|-----------|---------|------|
| CoreScene | `Assets/GameRes/Scenes` | AddressByFileName | PackSeparately | ✅ | 场景独立打包 |
| CoreUI | `Assets/GameRes/UI/Prefabs` | AddressByFileName | PackSeparately | ✅ | UI Panel 独立打包 |
| CoreAtlas | `Assets/GameRes/UI/Atlases` | AddressByFileName | PackDirectory | ✅ | 图集按目录打包 |
| CoreAudio | `Assets/GameRes/Audio` | AddressByFileName | PackDirectory | ✅ | 音频按目录打包 |
| CoreConfig | `Assets/GameRes/Configs` | AddressByFileName | PackGroup | ✅ | 配置表打成一个包 |
| Levels | `Assets/GameRes/Levels` | AddressByFileName | PackSeparately | 前 20 关 | 关卡独立打包 |
| Events | `Assets/GameRes/Events` | AddressByFileName | PackDirectory | ❌ | 活动按目录打包 |
| DLL | `HybridCLRData/HotUpdateDlls` | AddressByFileName | PackGroup | ✅ | 热更 DLL |
| AOTDLL | `HybridCLRData/AOTDlls` | AddressByFileName | PackGroup | ✅ | AOT 元数据 |

### 打包配置

```
Build Pipeline: ScriptableBuildPipeline
Package Name: DefaultPackage
Compress Option: LZ4
File Name Style: HashName          ← 避免路径泄露
Copy Buildin File Option: Copy     ← 核心资源复制到 StreamingAssets
```

> **注意**：只有需要进入首包的 Group 才勾选 "Copy Buildin File"。活动资源等不需要进入首包的 Group 选择 None，只上 CDN。

## 四、AssetManager 封装

### 4.1 设计目标

- 封装 YooAsset API，提供简洁的加载接口
- 统一管理 AssetHandle 引用计数，防止泄漏
- 支持同步/异步加载
- 自动处理加载失败情况（离线回退）

### 4.2 核心实现

```csharp
using System;
using System.Collections.Generic;
using UnityEngine;
using YooAsset;
using Cysharp.Threading.Tasks;
using Object = UnityEngine.Object;

/// <summary>
/// 资源管理器 — 封装 YooAsset，统一引用计数管理
/// </summary>
public class AssetManager
{
    private readonly ResourcePackage _package;
    private readonly Dictionary<string, AssetHandle> _handles = new();
    private readonly Dictionary<string, int> _refCounts = new();

    public AssetManager(ResourcePackage package)
    {
        _package = package ?? throw new ArgumentNullException(nameof(package));
    }

    /// <summary>
    /// 异步加载资源（自动引用计数）
    /// </summary>
    public async UniTask<T> LoadAsync<T>(string address) where T : Object
    {
        // 引用计数 +1
        if (_refCounts.TryGetValue(address, out int count))
        {
            _refCounts[address] = count + 1;
            if (_handles.TryGetValue(address, out var cached))
                return cached.AssetObject as T;
        }
        _refCounts[address] = 1;

        // 异步加载
        var handle = _package.LoadAssetAsync<T>(address);
        _handles[address] = handle;
        await handle.ToUniTask();

        if (handle.Status != EOperationStatus.Succeed)
        {
            Debug.LogError($"[AssetManager] 加载失败: {address}, {handle.LastError}");
            _refCounts.Remove(address);
            _handles.Remove(address);
            return null;
        }

        return handle.AssetObject as T;
    }

    /// <summary>
    /// 释放资源（引用计数归零才真正 Release）
    /// </summary>
    public void Release(string address)
    {
        if (!_refCounts.TryGetValue(address, out int count))
        {
            Debug.LogWarning($"[AssetManager] 释放未加载的资源: {address}");
            return;
        }

        count--;
        if (count <= 0)
        {
            // 引用归零，真正释放
            _refCounts.Remove(address);
            if (_handles.TryGetValue(address, out var handle))
            {
                handle.Release();
                _handles.Remove(address);
            }
        }
        else
        {
            _refCounts[address] = count;
        }
    }

    /// <summary>
    /// 异步加载并实例化 GameObject
    /// </summary>
    public async UniTask<GameObject> InstantiateAsync(string address, Transform parent = null)
    {
        var prefab = await LoadAsync<GameObject>(address);
        if (prefab == null) return null;
        return parent != null
            ? Object.Instantiate(prefab, parent)
            : Object.Instantiate(prefab);
    }

    /// <summary>
    /// 加载场景
    /// </summary>
    public async UniTask<SceneHandle> LoadSceneAsync(string sceneName)
    {
        var handle = _package.LoadSceneAsync(sceneName);
        await handle.ToUniTask();
        return handle;
    }

    /// <summary>
    /// 释放所有资源（场景切换时调用）
    /// </summary>
    public void ReleaseAll()
    {
        foreach (var handle in _handles.Values)
            handle.Release();
        _handles.Clear();
        _refCounts.Clear();
    }

    /// <summary>
    /// 检查资源是否存在（离线模式安全检查）
    /// </summary>
    public bool CheckAssetValid(string address)
    {
        var assetInfo = _package.GetAssetInfo(address);
        return assetInfo != null;
    }
}
```

### 4.3 使用示例

```csharp
// UI 加载
public class UIPanel : MonoBehaviour
{
    private AssetManager _assetMgr;
    private GameObject _instance;

    private async UniTaskVoid OpenPanel(string panelName)
    {
        _instance = await _assetMgr.InstantiateAsync(panelName, transform);
    }

    private void ClosePanel()
    {
        if (_instance != null)
        {
            Destroy(_instance);
            _assetMgr.Release(panelName); // 引用计数 -1
        }
    }
}
```

## 五、内存管理策略

### 5.1 Load/Release 配对规则

| 场景 | Load 时机 | Release 时机 |
|------|----------|-------------|
| UI Panel | 打开时 LoadAsync | 关闭时 Release |
| 角色 | 生成时 LoadAsync | 销毁时 Release |
| 场景 | 加载场景 LoadSceneAsync | 离开场景 UnloadScene |
| 配置表 | 首次访问 LoadAsync | 游戏退出时 ReleaseAll |
| 常驻 UI | 启动时 LoadAsync | 不释放 |

### 5.2 场景切换清理

```csharp
/// <summary>
/// 场景切换时的标准清理流程
/// </summary>
public async UniTask SwitchScene(string newScene)
{
    // 1. Release 所有旧场景资源
    _assetMgr.ReleaseAll();

    // 2. 等一帧让引用关系更新
    await UniTask.DelayFrame(1);

    // 3. 触发 GC 清理未引用资源
    Resources.UnloadUnusedAssets();
    GC.Collect();

    // 4. 加载新场景
    await _assetMgr.LoadSceneAsync(newScene);
}
```

> **注意**：不要在持有 AssetHandle 的资源时调用 `Resources.UnloadUnusedAssets()`，会误杀 YooAsset 持有的资源。详见 [[../../35_高级主题/【踩坑】YooAsset中大型项目踩坑实录]] 坑 3。

## 六、离线降级策略

```csharp
/// <summary>
/// 离线安全加载 — 加载失败时尝试回退
/// </summary>
public async UniTask<T> LoadSafeAsync<T>(string address) where T : Object
{
    // 检查资源是否存在
    if (!_assetMgr.CheckAssetValid(address))
    {
        Debug.LogWarning($"[AssetManager] 资源不存在（可能热更未完成）: {address}");

        // 尝试清理 Cache 层强制用 Buildin
        // 这是极端情况：Manifest 已更新但资源下载中断
        // 下次启动会自动修复，这里先回退到内置版本
    }

    return await _assetMgr.LoadAsync<T>(address);
}
```
