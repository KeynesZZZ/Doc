# 热更系统设计

> 单机休闲游戏的"代码 + 资源"双热更方案。核心策略：后台静默检查 → 静默下载 → 下次启动生效。无网络时游戏正常运行，热更永远不阻断玩家。

## 文档定位

- **YooAsset 热更基础**：[[../../35_高级主题/【笔记】YooAsset热更新与版本管理]] 已覆盖标准热更流程
- **HybridCLR 协同**：[[../../35_高级主题/【笔记】YooAsset与HybridCLR协同方案]] 已覆盖双热更架构
- **本文**：聚焦海外休闲单机游戏的特殊热更策略——静默热更 + 下次启动生效

## 一、为什么不用标准热更流程？

标准热更流程（检查→下载→进入游戏）对单机休闲游戏有三个致命问题：

| 问题 | 影响 |
|------|------|
| **阻断启动** | 玩家点击图标后要等下载才能玩，海外弱网体验极差 |
| **离线不可用** | 无网络时卡在热更检查界面，无法进入游戏 |
| **打扰玩家** | 休闲游戏玩家只玩 3-10 分钟，热更弹窗严重影响留存 |

**解决方案：静默热更 + 下次启动生效。**

```
标准流程（不适合休闲游戏）:
App 启动 → 检查版本 → 下载 → 进入游戏
           ^^^^^^^^^^^^^^^^^^^^ 玩家等待

休闲游戏流程（推荐）:
App 启动 → 立即进入游戏（用本地资源）
              │
              └── 后台静默检查 + 下载 → 标记 pending → 下次启动生效
```

## 二、热更流程全链路

```
App 启动
  │
  ▼
初始化 YooAsset (HostPlayMode)
  BuildinFileSystem  = 首包内置资源
  CacheFileSystem    = 热更缓存资源
  RemoteServices     = CDN 远端
  │
  ▼
加载本地 Manifest → 立即进入游戏 ← 不等网络
  │
  ├── 启动后台静默热更任务
  │     │
  │     ├─ 网络不可达？ → 跳过，下次再检查
  │     │
  │     ├─ 请求远端版本号（5 秒超时）
  │     │   └─ 超时/失败 → 跳过
  │     │
  │     ├─ 版本一致？ → 无需更新
  │     │
  │     ├─ 更新 Manifest
  │     │
  │     ├─ 创建下载器
  │     │   └─ 下载量 > 50MB？ → 跳过（WiFi 下再下载）
  │     │
  │     ├─ 静默下载（低并发，不弹 UI）
  │     │   └─ 下载中断？ → 断点续传，下次继续
  │     │
  │     └─ 下载完成 → 标记 pending_version → 本次不切换
  │
  ▼（玩家正常游戏）
  │
  ▼（玩家退出，下次启动）
  │
  ▼
检测到 pending_version → Cache 层已更新 → 新版本自动生效
```

## 三、版本号机制

### 3.1 三个版本号

| 版本号 | 存储位置 | 用途 |
|--------|---------|------|
| `ActiveVersion` | PlayerPrefs | 当前正在使用的资源版本 |
| `PendingVersion` | PlayerPrefs | 已下载完成，等待下次启动生效的版本 |
| 远端版本号 | CDN `manifest.hash` | CDN 上最新的资源版本 |

### 3.2 版本切换逻辑

```
场景 1: 正常热更
  ActiveVersion = "1.0.0"
  远端版本 = "1.0.1"
  → 后台下载完成
  → PendingVersion = "1.0.1"
  → 下次启动: ActiveVersion = "1.0.1"，新版本生效

场景 2: 下载中断
  ActiveVersion = "1.0.0"
  远端版本 = "1.0.1"
  → 下载中断
  → PendingVersion 未设置
  → 下次启动: ActiveVersion 仍为 "1.0.0"，使用旧版本
  → 下次静默检查时断点续传继续下载

场景 3: 代码版本与资源版本绑定
  代码和资源通过同一个 YooAsset Package 分发
  → Manifest 更新时，HotUpdate.dll 和资源一起更新
  → 版本天然对齐
```

## 四、版本配置服务

单机游戏不需要复杂服务端，用 CDN 上的轻量 JSON 即可：

### 4.1 version_config.json

```json
{
    "latestVersion": "1.2.3",
    "minAppVersion": "1.0.0",
    "forceUpdate": false,
    "resourceVersion": "1.2.3",
    "announcement": {
        "en": "Bug fixes and new levels!",
        "ja": "バグ修正と新しいレベル！",
        "ko": "버그 수정 및 새로운 레벨!",
        "de": "Fehlerbehebungen und neue Level!"
    }
}
```

放置在 CDN 根目录：`https://{cdn-host}/version_config.json`

### 4.2 客户端版本检查

```csharp
using UnityEngine;
using System;
using System.Threading;
using Cysharp.Threading.Tasks;
using UnityEngine.Networking;

/// <summary>
/// 版本配置管理器 — 请求远端版本配置，决定热更策略
/// </summary>
public class VersionConfigManager
{
    [Serializable]
    public class VersionConfig
    {
        public string latestVersion;
        public string minAppVersion;
        public bool forceUpdate;
        public string resourceVersion;
        public Announcement announcement;
    }

    [Serializable]
    public class Announcement
    {
        public string en;
        public string ja;
        public string ko;
        public string de;
    }

    /// <summary>
    /// 请求版本配置（带 5 秒超时）
    /// </summary>
    public static async UniTask<VersionConfig> FetchConfig(string url)
    {
        try
        {
            using var req = UnityNetworking.Get(url);
            req.timeout = 5;
            req.SendWebRequest();
            await UniTask.WaitUntil(() => req.isDone);
            if (req.result != UnityWebRequest.Result.Success)
            {
                Debug.LogWarning($"[VersionConfig] 请求失败: {req.error}");
                return null;
            }
            return JsonUtility.FromJson<VersionConfig>(req.downloadHandler.text);
        }
        catch (Exception e)
        {
            Debug.LogWarning($"[VersionConfig] 异常: {e.Message}");
            return null;
        }
    }

    /// <summary>
    /// 检查是否需要强制更新整包
    /// </summary>
    public static bool NeedForceUpdate(VersionConfig config, string currentAppVersion)
    {
        if (config == null) return false;
        return CompareVersion(currentAppVersion, config.minAppVersion) < 0;
    }

    /// <summary>
    /// 语义化版本比较: 返回 -1/0/1
    /// </summary>
    public static int CompareVersion(string v1, string v2)
    {
        var p1 = v1.Split('.');
        var p2 = v2.Split('.');
        for (int i = 0; i < Mathf.Max(p1.Length, p2.Length); i++)
        {
            int a = i < p1.Length ? int.Parse(p1[i]) : 0;
            int b = i < p2.Length ? int.Parse(p2[i]) : 0;
            if (a != b) return a.CompareTo(b);
        }
        return 0;
    }
}
```

## 五、HotUpdateManager 完整实现

```csharp
using UnityEngine;
using YooAsset;
using Cysharp.Threading.Tasks;
using System.Threading;

/// <summary>
/// 静默热更管理器 — 后台检查+下载，下次启动生效，不阻断游戏
/// </summary>
public class HotUpdateManager
{
    private readonly ResourcePackage _package;
    private readonly string _versionConfigUrl;

    // 下载量阈值：超过此值在移动网络下不自动下载
    private const long WiFiOnlyThreshold = 50 * 1024 * 1024; // 50MB

    public HotUpdateManager(ResourcePackage package, string versionConfigUrl)
    {
        _package = package;
        _versionConfigUrl = versionConfigUrl;
    }

    /// <summary>
    /// 执行静默热更（fire and forget，调用方不需要 await）
    /// </summary>
    public async UniTaskVoid RunSilentUpdate()
    {
        // 检查 pending 版本是否已生效
        CheckPendingVersion();

        // 无网络直接跳过
        if (Application.internetReachability == NetworkReachability.NotReachable)
        {
            Debug.Log("[热更] 无网络，跳过检查");
            return;
        }

        // 请求版本配置
        var config = await VersionConfigManager.FetchConfig(_versionConfigUrl);
        if (config == null)
        {
            Debug.Log("[热更] 版本配置获取失败，使用本地资源");
            return;
        }

        // 强制整包更新检查
        if (VersionConfigManager.NeedForceUpdate(config, Application.version))
        {
            Debug.Log("[热更] 需要强制更新整包，弹出商店跳转");
            // TODO: 弹出强制更新弹窗，引导玩家去商店
            return;
        }

        // 请求 YooAsset 远端版本号
        var versionOp = _package.RequestPackageVersionAsync();
        bool cancelled = await UniTask.WaitUntil(
            () => versionOp.IsDone,
            cancellationToken: CreateTimeoutCts(5000)
        ).SuppressCancellationThrow();

        if (!versionOp.IsDone || versionOp.Status != EOperationStatus.Succeed)
        {
            Debug.Log("[热更] 远端版本号获取失败/超时");
            return;
        }

        string remoteVersion = versionOp.PackageVersion;
        string localVersion = PlayerPrefs.GetString("ActiveVersion", "");

        if (remoteVersion == localVersion)
        {
            Debug.Log("[热更] 已是最新版本");
            return;
        }

        // 更新 Manifest
        var manifestOp = _package.UpdatePackageManifestAsync(remoteVersion);
        await manifestOp.ToUniTask();
        if (manifestOp.Status != EOperationStatus.Succeed)
        {
            Debug.Log("[热更] Manifest 更新失败");
            return;
        }

        // 创建下载器
        var downloader = _package.CreateResourceDownloader(
            downloadingMax: 3,   // 低并发，不抢带宽
            failedRetry: 3
        );

        if (downloader.TotalDownloadCount == 0)
        {
            PlayerPrefs.SetString("ActiveVersion", remoteVersion);
            return;
        }

        // 移动网络下大文件不自动下载
        if (Application.internetReachability == NetworkReachability.ReachableViaCarrierDataNetwork &&
            downloader.TotalDownloadBytes > WiFiOnlyThreshold)
        {
            Debug.Log($"[热更] 下载量过大 ({downloader.TotalDownloadBytes / 1024 / 1024}MB)，" +
                      $"移动网络下跳过，等待 WiFi");
            return;
        }

        // 静默下载
        Debug.Log($"[热更] 开始下载: {downloader.TotalDownloadCount} 个文件, " +
                  $"{downloader.TotalDownloadBytes / 1024}KB");

        downloader.OnDownloadError += (ctx) =>
        {
            Debug.LogWarning($"[热更] 下载错误: {ctx.FileName}");
        };

        downloader.BeginDownload();
        await downloader.ToUniTask();

        if (downloader.Status == EOperationStatus.Succeed)
        {
            PlayerPrefs.SetString("PendingVersion", remoteVersion);
            PlayerPrefs.SetString("ActiveVersion", remoteVersion);
            Debug.Log($"[热更] 版本 {remoteVersion} 下载完成，下次启动生效");
        }
        else
        {
            Debug.LogWarning("[热更] 下载未完成，下次启动断点续传");
        }
    }

    /// <summary>
    /// 检查是否有已下载完成但未生效的版本
    /// </summary>
    private void CheckPendingVersion()
    {
        string pending = PlayerPrefs.GetString("PendingVersion", "");
        if (!string.IsNullOrEmpty(pending))
        {
            Debug.Log($"[热更] 检测到 pending 版本 {pending}，本次启动自动生效");
            PlayerPrefs.DeleteKey("PendingVersion");
            // Cache 层已被 YooAsset 自动挂载，无需额外操作
        }
    }

    private CancellationTokenSource CreateTimeoutCts(int ms)
    {
        var cts = new CancellationTokenSource(ms);
        return cts;
    }
}
```

## 七、海外 CDN 部署

### 7.1 多区域 CDN

```csharp
/// <summary>
/// 海外多区域 CDN — 根据玩家地区选择最近节点
/// </summary>
public class GameRemoteServices : IRemoteServices
{
    private readonly string _mainUrl;
    private readonly string _fallbackUrl;

    public GameRemoteServices()
    {
        string region = GetPlayerRegion();
        string cdnBase = region switch
        {
            "us"    => "https://us-cdn.yourgame.com",
            "eu"    => "https://eu-cdn.yourgame.com",
            "asia"  => "https://asia-cdn.yourgame.com",
            _       => "https://global-cdn.yourgame.com"
        };

        string platform = GetPlatformDir();
        _mainUrl = $"{cdnBase}/{platform}/DefaultPackage";
        _fallbackUrl = $"https://global-cdn.yourgame.com/{platform}/DefaultPackage";
    }

    public string GetRemoteMainURL(string fileName) => $"{_mainUrl}/{fileName}";
    public string GetRemoteFallbackURL(string fileName) => $"{_fallbackUrl}/{fileName}";

    private static string GetPlayerRegion()
    {
        // 方案 1: 根据 SystemLanguage
        return Application.systemLanguage switch
        {
            SystemLanguage.Japanese => "asia",
            SystemLanguage.Korean => "asia",
            SystemLanguage.Chinese => "asia",
            SystemLanguage.German => "eu",
            SystemLanguage.French => "eu",
            _ => "us"
        };
    }

    private static string GetPlatformDir()
    {
#if UNITY_ANDROID
        return "android";
#elif UNITY_IOS
        return "ios";
#else
        return "universal";
#endif
    }
}
```

### 7.2 CDN 目录结构

```
CDN 根目录/
├── version_config.json          ← 版本配置（全局唯一）
│
├── android/
│   └── DefaultPackage/
│       ├── manifest.hash
│       ├── manifest.bytes
│       └── bundles/
│           ├── v1.0.0/          ← 旧版本（灰度回退用）
│           └── v1.2.3/          ← 最新版本
│
├── ios/
│   └── DefaultPackage/
│       └── ...
│
└── universal/                    ← 编辑器/Steam 等
    └── DefaultPackage/
        └── ...
```

### 7.3 灰度发布

```
灰度策略：
1. 全量用户 → v1.2.2
2. 灰度 10% 用户 → v1.2.3
   └── 客户端请求 version_config.json 时带 User-ID
   └── 服务端根据 ID 返回灰度版本号
3. 观察 24h，无问题 → 灰度 50%
4. 全量 → v1.2.3
5. 旧版本 v1.2.2 CDN 保留 7 天
```

## 八、边界情况处理

### 8.1 网络中断

```csharp
// YooAsset 下载器自动重试（failedRetry: 3）
// 重试次数用尽后 Status 变为 Failed
// 下次启动时 CreateResourceDownloader 会跳过已下载文件，断点续传
```

### 8.2 磁盘空间不足

```csharp
// 下载前检查（Android 通过 Native Plugin 获取可用空间）
long available = GetAvailableDiskSpace();
long need = downloader.TotalDownloadBytes;

if (need > available)
{
    Debug.LogWarning($"[热更] 磁盘空间不足: 需要 {need/1024/1024}MB, " +
                     $"可用 {available/1024/1024}MB");
    // 休闲游戏：静默跳过，不弹窗打扰玩家
    return;
}
```

### 8.3 版本回退

```
方案：CDN 保留旧版本目录 + version_config.json 指向旧版本

version_config.json:
{
    "resourceVersion": "1.2.2",  // ← 改回旧版本号
    ...
}

客户端检测到版本号变化 → 自动回退到旧版本
```

## 九、决策总结

| 决策点 | 推荐 | 理由 |
|--------|------|------|
| 热更时机 | 后台静默 | 不阻断游戏 |
| 生效时机 | 下次启动 | 避免运行时切换的复杂性 |
| 并发下载数 | 3 | 不抢带宽 |
| 版本检查超时 | 5 秒 | 弱网快速 fallback |
| 移动网络下载阈值 | 50MB | 避免大流量消耗 |
| 强制热更 | 从不 | 单机游戏永远不阻断 |
| 多 Package | 不需要 | 休闲游戏单 Package 足够 |
