在休闲游戏项目中，发现以下问题：
- 游戏运行30分钟后内存从150MB增长到480MB

## 2. 定位瓶颈

### 2.1 Memory Profiler 快照对比使用流程

#### 核心原则：同状态 + 排除干扰

快照对比的关键不是拍得多，而是**两个快照处于相同的业务状态**，确保差异是真正的泄漏而非临时对象。

#### 步骤1：捕获基准快照

```
1. 启动游戏，进入主菜单
2. Window > Analysis > Memory Profiler
3. 手动触发 GC（排除临时对象干扰）：
   - 调用 GC.Collect() + Resources.UnloadUnusedAssets()
   - 或按 F8（需自建快捷键，见下方代码）
4. 等待2秒（让 GC 和异步卸载完成）
5. 点击 "Capture Snapshot"
6. 命名为 "Baseline_MainMenu"
```

```csharp
// 测试辅助工具：手动触发 GC，确保快照干净
#if UNITY_EDITOR
public class MemorySnapshotHelper : MonoBehaviour
{
    private void Update()
    {
        if (Input.GetKeyDown(KeyCode.F8))
        {
            // 先 GC 再延迟拍快照，排除临时对象干扰
            GC.Collect();
            GC.WaitForPendingFinalizers();
            GC.Collect();
            Resources.UnloadUnusedAssets();
            Debug.Log("[Memory] GC 完成，2秒后可拍快照");
        }
    }
}
#endif
```

#### 步骤2：捕获操作后快照（重复多次）

```
1. 进入关卡，玩一局游戏
2. 返回主菜单                    ← 必须回到和快照A完全相同的状态
3. 手动触发 GC（同步骤1）
4. 等待2秒
5. 捕获快照 "After_Game_01"
6. 重复3次，捕获 "After_Game_02", "After_Game_03"
```

**为什么要拍多次？**
- 一次对比可能混入偶发对象
- 多次快照能区分"线性增长（泄漏）"和"增长后稳定（缓存）"

#### 步骤3：对比分析（四种筛选模式）

打开 Compare 模式后，Memory Profiler 提供四种关键筛选，**按以下顺序查看**：

```
1. 选择 "Compare" 模式
2. 左侧选择 "Baseline_MainMenu"
3. 右侧选择 "After_Game_03"

查看顺序：
├── ① New Objects（B有A没有）     ← 最关键！泄漏候选
├── ② Surviving Objects (Size Delta)  ← 按大小增量排序，找增长最多的
├── ③ Deleted Objects               ← 确认资源确实在卸载（健康指标）
└── ④ Count Delta                   ← 按数量增量排序，找重复创建的对象
```

**四种筛选含义与用途**：

| 筛选模式 | 含义 | 主要用途 |
|----------|------|----------|
| **New Objects** | 快照B有、A没有的对象 | **定位泄漏** — 这些就是泄漏候选 |
| **Deleted Objects** | 快照A有、B没有的对象 | **验证卸载** — 确认资源确实在释放 |
| **Surviving Objects** | 两个快照都有的对象 | **检测增长** — 对比 Size Delta 找膨胀 |
| **Count Delta / Size Delta** | 按增量排序 | **快速定位** — 找最大泄漏源 |

**操作路径**：

```
① 选 "New Objects" → 按 Size 降序排列
  → 找到占内存最大的新增类型（如 Texture2D +125MB）

② 点选某个类型（如 Texture2D）→ 下方 Tree Map 展开
  → 看具体是哪些 Texture2D（如 "Background_01", "Background_02"...）

③ 点选具体对象 → 右侧 "References" 面板
  → 展开引用链，追踪到 GC Root（见步骤4）
```

#### 步骤4：引用链追踪（定位根因的关键）

References 面板从泄漏对象**往回找引用者**，直到找到 GC Root。这是从"知道泄漏了什么"到"知道为什么泄漏"的关键一步。

```
References（谁引用了我）—— 以泄漏的 Texture2D 为例：

Texture2D "Background_03"         ← 🔴 泄漏对象
  ↑ 被引用于
Sprite (Sprite.Create 产生的)      ← 中间对象
  ↑ 被引用于
Image.sprite (UnityEngine.UI.Image)
  ↑ 被引用于
GameObject "LevelBackground"
  ↑ 被引用于
GameObject "Canvas_B"
  ↑ 被引用于
[DontDestroyOnLoad]                ← 🔴 GC Root！根因在这里
```

看到 `DontDestroyOnLoad` 就知道根因：场景切换时这个常驻对象没有清理子物体，持有了一整条引用链。

**常见 GC Root 及对应的泄漏原因**：

| GC Root 类型 | 含义 | 典型泄漏原因 |
|-------------|------|-------------|
| `DontDestroyOnLoad` | 常驻对象 | 场景切换时没清理子物体或引用 |
| `static field` | 静态字段 | 静态集合/单例持有引用未释放 |
| `local variable` | 活动栈帧 | 协程中的局部变量未释放 |
| `Managed Wrapper` | Native 对象的 C# 包装 | Texture/Mesh 未显式 Destroy |

#### 步骤5：多次快照趋势确认

拍3~4次快照后，对比每次的增量，判断是"泄漏"还是"缓存"：

```
快照对比矩阵（同状态对比）：

              Baseline    Game1    Game2    Game3    判定
Texture2D数:     42         87      132      145    → 线性增长 = 泄漏 🔴
Mesh数:          15         16       17       18    → 稳定波动 = 正常 🟢
AudioClip数:     8          22       24       24    → 增长后稳定 = 缓存上限 🟡
GameObject数:   320        560      810      1020   → 线性增长 = 泄漏 🔴
```

**判断标准**：

| 趋势 | 含义 | 处理方式 |
|------|------|----------|
| **线性持续增长** | 每次操作都新增、不释放 | 泄漏，必须修复 |
| **增长后趋于稳定** | 前几次增长，后续不再增加 | 缓存上限，通常可接受 |
| **波动（有增有减）** | 增减交替 | 正常的加载/卸载，无泄漏 |

## 3. 解决方案

### 3.1 解决Texture2D泄漏

**方案**：使用 Addressables + 显式卸载

```csharp
/// <summary>
/// 资源管理器 - 统一管理资源加载和卸载
/// </summary>
public class ResourceManager : MonoBehaviour
{
    private Dictionary<string, AsyncOperationHandle> loadedAssets = new Dictionary<string, AsyncOperationHandle>();

    /// <summary>
    /// 异步加载资源
    /// </summary>
    public async Task<T> LoadAssetAsync<T>(string address) where T : Object
    {
        if (loadedAssets.TryGetValue(address, out var existingHandle))
        {
            return existingHandle.Result as T;
        }

        var handle = Addressables.LoadAssetAsync<T>(address);
        await handle.Task;

        if (handle.Status == AsyncOperationStatus.Succeeded)
        {
            loadedAssets[address] = handle;
            return handle.Result;
        }

        Debug.LogError($"Failed to load asset: {address}");
        return null;
    }

    /// <summary>
    /// 卸载指定资源
    /// </summary>
    public void UnloadAsset(string address)
    {
        if (loadedAssets.TryGetValue(address, out var handle))
        {
            Addressables.Release(handle);
            loadedAssets.Remove(address);
        }
    }

    /// <summary>
    /// 卸载所有资源（场景切换时调用）
    /// </summary>
    public void UnloadAll()
    {
        foreach (var handle in loadedAssets.Values)
        {
            Addressables.Release(handle);
        }
        loadedAssets.Clear();

        // 强制GC
        Resources.UnloadUnusedAssets();
        GC.Collect();
    }

    /// <summary>
    /// 场景切换时自动清理
    /// </summary>
    private void OnSceneUnloaded(Scene scene)
    {
        // 清理该场景加载的资源
        var keysToRemove = loadedAssets.Keys
            .Where(k => k.StartsWith($"Scenes/{scene.name}"))
            .ToList();

        foreach (var key in keysToRemove)
        {
            UnloadAsset(key);
        }
    }
}
```

**使用示例**：

```csharp
public class LevelManager : MonoBehaviour
{
    [SerializeField] private ResourceManager resourceManager;

    private string currentBackgroundKey;

    public async Task LoadLevel(int levelId)
    {
        // 卸载旧资源
        if (!string.IsNullOrEmpty(currentBackgroundKey))
        {
            resourceManager.UnloadAsset(currentBackgroundKey);
        }

        // 加载新资源
        currentBackgroundKey = $"Levels/Background_{levelId}";
        var texture = await resourceManager.LoadAssetAsync<Texture2D>(currentBackgroundKey);

        if (texture != null)
        {
            backgroundImage.sprite = Sprite.Create(texture,
                new Rect(0, 0, texture.width, texture.height),
                Vector2.zero);
        }
    }
}
```

### 3.2 解决事件泄漏

**方案**：使用安全的订阅模式

```csharp
/// <summary>
/// 安全的事件订阅基类
/// </summary>
public abstract class EventSubscriber : MonoBehaviour
{
    private List<Action> unsubscribeActions = new List<Action>();

    /// <summary>
    /// 安全订阅事件
    /// </summary>
    protected void SafeSubscribe<T>(EventChannel<T> channel, Action<T> handler)
    {
        channel.Subscribe(handler);
        unsubscribeActions.Add(() => channel.Unsubscribe(handler));
    }

    /// <summary>
    /// 自动取消所有订阅
    /// </summary>
    protected virtual void OnDestroy()
    {
        foreach (var unsubscribe in unsubscribeActions)
        {
            unsubscribe?.Invoke();
        }
        unsubscribeActions.Clear();
    }
}

/// <summary>
/// 使用示例
/// </summary>
public class GameUI : EventSubscriber
{
    [SerializeField] private EventChannel<int> scoreChannel;

    protected override void Awake()
    {
        base.Awake();
        SafeSubscribe(scoreChannel, UpdateScore);
    }

    private void UpdateScore(int score)
    {
        scoreText.text = score.ToString();
    }
}
```

**方案2：使用弱引用事件系统**

```csharp
/// <summary>
/// 弱引用事件系统 - 不会阻止订阅者被GC
/// </summary>
public class WeakEventChannel<T>
{
    private List<WeakReference<Action<T>>> subscribers = new List<WeakReference<Action<T>>>();

    public void Subscribe(Action<T> handler)
    {
        subscribers.Add(new WeakReference<Action<T>>(handler));
    }

    public void Publish(T data)
    {
        // 清理已释放的订阅者
        subscribers.RemoveAll(weakRef =>
        {
            if (!weakRef.TryGetTarget(out var handler))
            {
                return true; // 移除已GC的订阅者
            }
            handler.Invoke(data);
            return false;
        });
    }
}
```

### 3.3 解决协程泄漏

**方案**：显式管理协程生命周期

```csharp
/// <summary>
/// 协程管理器 - 自动追踪和清理协程
/// </summary>
public class CoroutineTracker : MonoBehaviour
{
    private Dictionary<string, Coroutine> activeCoroutines = new Dictionary<string, Coroutine>();

    /// <summary>
    /// 启动追踪协程
    /// </summary>
    public void StartTrackedCoroutine(string key, IEnumerator routine)
    {
        // 如果已存在同名协程，先停止
        StopTrackedCoroutine(key);

        activeCoroutines[key] = StartCoroutine(routine);
    }

    /// <summary>
    /// 停止指定协程
    /// </summary>
    public void StopTrackedCoroutine(string key)
    {
        if (activeCoroutines.TryGetValue(key, out var coroutine))
        {
            StopCoroutine(coroutine);
            activeCoroutines.Remove(key);
        }
    }

    /// <summary>
    /// 停止所有协程
    /// </summary>
    public void StopAllTrackedCoroutines()
    {
        foreach (var coroutine in activeCoroutines.Values)
        {
            StopCoroutine(coroutine);
        }
        activeCoroutines.Clear();
    }

    /// <summary>
    /// 对象销毁时自动清理
    /// </summary>
    private void OnDestroy()
    {
        StopAllTrackedCoroutines();
    }
}

/// <summary>
/// 使用示例
/// </summary>
public class EffectPlayer : MonoBehaviour
{
    private CoroutineTracker tracker;

    private void Awake()
    {
        tracker = gameObject.AddComponent<CoroutineTracker>();
    }

    public void PlayEffect()
    {
        tracker.StartTrackedCoroutine("EffectLoop", PlayEffectLoop());
    }

    public void StopEffect()
    {
        tracker.StopTrackedCoroutine("EffectLoop");
    }

    private IEnumerator PlayEffectLoop()
    {
        while (true)
        {
            // 播放特效
            yield return new WaitForSeconds(1f);
        }
    }
}
```

### 3.4 解决对象池泄漏

**方案**：场景感知的对象池

```csharp
/// <summary>
/// 场景感知对象池 - 自动清理场景切换时的引用
/// </summary>
public class SceneAwarePool<T> : IDisposable where T : Component
{
    private Stack<T> pool = new Stack<T>();
    private HashSet<T> activeObjects = new HashSet<T>();
    private T prefab;
    private Transform poolContainer;
    private Scene ownerScene;

    public SceneAwarePool(T prefab, int initialSize, Scene scene)
    {
        this.prefab = prefab;
        this.ownerScene = scene;

        // 创建容器
        var containerObj = new GameObject($"Pool_{typeof(T).Name}");
        SceneManager.MoveGameObjectToScene(containerObj, scene);
        poolContainer = containerObj.transform;

        // 预热
        for (int i = 0; i < initialSize; i++)
        {
            var obj = CreateNew();
            obj.gameObject.SetActive(false);
            pool.Push(obj);
        }

        // 注册场景卸载事件
        SceneManager.sceneUnloaded += OnSceneUnloaded;
    }

    public T Get()
    {
        T obj;

        if (pool.Count > 0)
        {
            obj = pool.Pop();
        }
        else
        {
            obj = CreateNew();
        }

        obj.gameObject.SetActive(true);
        activeObjects.Add(obj);
        return obj;
    }

    public void Return(T obj)
    {
        if (activeObjects.Remove(obj))
        {
            obj.gameObject.SetActive(false);
            obj.transform.SetParent(poolContainer);
            pool.Push(obj);
        }
    }

    private T CreateNew()
    {
        var obj = GameObject.Instantiate(prefab, poolContainer);
        SceneManager.MoveGameObjectToScene(obj.gameObject, ownerScene);
        return obj;
    }

    private void OnSceneUnloaded(Scene unloadedScene)
    {
        if (unloadedScene == ownerScene)
        {
            Dispose();
        }
    }

    public void Dispose()
    {
        SceneManager.sceneUnloaded -= OnSceneUnloaded;

        // 销毁所有对象
        foreach (var obj in activeObjects)
        {
            if (obj != null) GameObject.Destroy(obj.gameObject);
        }
        foreach (var obj in pool)
        {
            if (obj != null) GameObject.Destroy(obj.gameObject);
        }

        activeObjects.Clear();
        pool.Clear();

        if (poolContainer != null)
        {
            GameObject.Destroy(poolContainer.gameObject);
```

```csharp
/// <summary>

{
    /// <summary>
    /// 检测潜在的事件泄漏

    {
        var allMonoBehaviours = GameObject.FindObjectsOfType<MonoBehaviour>();

            var hasOnDisable = type.GetMethod("OnDisable", BindingFlags.NonPublic | BindingFlags.Instance) != null;

        }
    }

    /// 检测静态引用
    /// </summary>
    [MenuItem("Tools/Memory/Check Static References")]
    public static void CheckStaticReferences()
    {
        var staticFields = new List<string>();

        foreach (var assembly in AppDomain.CurrentDomain.GetAssemblies())
        {
            try
            {
                foreach (var type in assembly.GetTypes())
                {
                    if (!type.IsClass) continue;

                    foreach (var field in type.GetFields(BindingFlags.Static | BindingFlags.NonPublic | BindingFlags.Public))

                            if (value != null)
                            {
                                staticFields.Add($"{type.Name}.{field.Name} = {value}");
                            }
                        }
                    }
                }
            }
            catch { }
        }

        if (staticFields.Count > 0)
        {
            Debug.LogWarning($"发现 {staticFields.Count} 个静态引用：\n{string.Join("\n", staticFields)}");
        }
        else
        {
            Debug.Log("未发现静态引用问题");
        }
    }
```

### 6.2 第一层：二分隔离 — 锁定泄漏系统

**原理**：逐个关闭子系统，跑同样的场景切换流程，对比泄漏量变化。

```csharp
/// <summary>
/// 泄漏二分排查工具
/// 逐个关闭子系统，看泄漏是否消失，快速锁定最大嫌疑
/// </summary>
public class LeakIsolator : MonoBehaviour
{
    [Header("子系统开关（测试时逐个关闭）")]
    [SerializeField] private bool enableInventory = true;
    [SerializeField] private bool enableShop = true;
    [SerializeField] private bool enableBattle = true;
    [SerializeField] private bool enableAudio = true;

    [Header("测试参数")]
    [SerializeField] private int testRounds = 5;
    [SerializeField] private float waitAfterGC = 2f;

    private int baselineTextureCount;

    [MenuItem("Tools/Memory/Run Leak Isolation")]
    public void RunTest()
    {
        baselineTextureCount = CountAssets<Texture2D>();
        StartCoroutine(RunIsolationTest());
    }

    private IEnumerator RunIsolationTest()
    {
        // 全部开启 → 记录基准泄漏量
        var allOnLeak = yield return MeasureLeak("全部开启");
        Debug.Log($"[Isolator] 基准泄漏: {allOnLeak} 个 Texture2D");

        // 逐个关闭测试
        enableInventory = false;
        var noInvLeak = yield return MeasureLeak("关闭背包");
        LogDelta("背包系统", allOnLeak, noInvLeak);

        enableInventory = true;
        enableShop = false;
        var noShopLeak = yield return MeasureLeak("关闭商店");
        LogDelta("商店系统", allOnLeak, noShopLeak);

        enableShop = true;
        enableAudio = false;
        var noAudioLeak = yield return MeasureLeak("关闭音频");
        LogDelta("音频系统", allOnLeak, noAudioLeak);
    }

    private void LogDelta(string system, int baselineLeak, int currentLeak)
    {
        var delta = baselineLeak - currentLeak;
        if (delta > 2)
            Debug.LogWarning($"[Isolator] 🔴 {system} 贡献了 ~{delta} 个泄漏");
        else
            Debug.Log($"[Isolator] 🟢 {system} 无泄漏");
    }

    private IEnumerator MeasureLeak(string label)
    {
        GC.Collect();
        GC.WaitForPendingFinalizers();
        GC.Collect();
        yield return new WaitForSeconds(waitAfterGC);
        var before = CountAssets<Texture2D>();

        for (int i = 0; i < testRounds; i++)
        {
            yield return SceneManager.LoadSceneAsync("Level_01");
            yield return new WaitForSeconds(0.5f);
            yield return SceneManager.LoadSceneAsync("MainMenu");
        }

        GC.Collect();
        yield return new WaitForSeconds(waitAfterGC);
        var after = CountAssets<Texture2D>();

        Debug.Log($"[Isolator] {label}: {before} → {after} (增量 {after - before})");
    }

    private static int CountAssets<T>() where T : Object =>
        Resources.FindObjectsOfTypeAll<T>().Length;
}
```

```
[Isolator] 🔴 背包系统 贡献了 ~30 个泄漏     ← 最大嫌疑
[Isolator] 🔴 商店系统 贡献了 ~10 个泄漏
```

### 6.3 第二层：资源分配追踪 — 定位到代码行

**原理**：Hook 资源加载入口，记录每次加载的调用栈；场景卸载后检查"哪些加载的资源还活着"。

```csharp
/// <summary>
/// 资源分配追踪器
/// 在资源加载时记录调用栈，场景卸载后自动报告泄漏资源和加载位置
/// 需要 ResourceManager 在加载完成时触发 OnAssetLoaded 回调
/// </summary>
public class AssetAllocationTracker : MonoBehaviour
{
    private readonly Dictionary<string, AllocationInfo> records = new();

    private struct AllocationInfo
    {
        public string AssetName;
        public string StackTrace;    // 加载时的调用栈
        public string SceneName;     // 在哪个场景加载的
        public float LoadTime;       // 加载时间
    }

    private void OnEnable()
    {
        ResourceManager.OnAssetLoaded += RecordAllocation;
        SceneManager.sceneUnloaded += OnSceneUnloaded;
    }

    private void RecordAllocation(string assetPath, Object asset)
    {
        records[assetPath] = new AllocationInfo
        {
            AssetName = assetPath,
            // 捕获调用栈（跳过前3帧系统代码，定位到业务代码）
            StackTrace = new System.Diagnostics.StackTrace(3, true).ToString(),
            SceneName = SceneManager.GetActiveScene().name,
            LoadTime = Time.time
        };
    }

    private void OnSceneUnloaded(Scene unloaded)
    {
        var sceneAssets = records
            .Where(kvp => kvp.Value.SceneName == unloaded.name)
            .ToList();

        StartCoroutine(CheckSurvivingAssets(sceneAssets));
    }

    /// <summary>
    /// 延迟检查：场景卸载后哪些资源还活着 = 泄漏
    /// </summary>
    private IEnumerator CheckSurvivingAssets(
        List<KeyValuePair<string, AllocationInfo>> sceneAssets)
    {
        // 等 GC 和异步卸载完成
        yield return new WaitForSeconds(1f);
        GC.Collect();
        yield return new WaitForSeconds(1f);

        var survivingTextures = Resources.FindObjectsOfTypeAll<Texture2D>()
            .Select(t => t.name)
            .ToHashSet();

        foreach (var kvp in sceneAssets)
        {
            var assetName = System.IO.Path.GetFileNameWithoutExtension(kvp.Key);

            if (survivingTextures.Contains(assetName))
            {
                // 🔴 找到泄漏源！直接打印加载代码位置
                Debug.LogError($"[LeakTracker] 🔴 泄漏资源: {assetName}\n" +
                               $"  加载场景: {kvp.Value.SceneName}\n" +
                               $"  加载时间: {kvp.Value.LoadTime:F1}s\n" +
                               $"  调用栈:\n{kvp.Value.StackTrace}");
            }
        }
    }

    private void OnDisable()
    {
        ResourceManager.OnAssetLoaded -= RecordAllocation;
        SceneManager.sceneUnloaded -= OnSceneUnloaded;
    }
}
```

**输出示例**（直接定位到代码行）：

### 6.4 运行时内存监控 — 不拍快照的持续检测

**原理**：每 N 秒统计关键资源数量，发现异常增长自动报警。可接入日志服务器做线上监控。

```csharp
/// <summary>
/// 运行时内存监控器
/// 每 N 秒检查关键资源数量，自动报警异常增长
/// 可挂在 DontDestroyOnLoad 对象上常驻运行
/// </summary>
public class MemoryMonitor : MonoBehaviour
{
    [Header("监控间隔")]
    [SerializeField] private float checkInterval = 5f;

    [Header("报警阈值")]
    [SerializeField] private int textureWarning = 80;
    [SerializeField] private int gameObjectWarning = 500;
    [SerializeField] private int singleRoundGrowthWarning = 5;

    // 上次记录值（用于增量计算）
    private int lastTextureCount;
    private int lastGameObjectCount;
    private int checkRound;

    private void Start()
    {
        InvokeRepeating(nameof(Check), checkInterval, checkInterval);
    }

    private void Check()
    {
        checkRound++;
        var tex = CountAssets<Texture2D>();
        var go = CountObjects<GameObject>();
        var heap = GC.GetTotalMemory(false);

        var texDelta = tex - lastTextureCount;
        var goDelta = go - lastGameObjectCount;

        // 阈值报警
        if (tex > textureWarning)
            Debug.LogWarning($"[MemoryMonitor] ⚠️ Texture2D 异常: {tex} (阈值 {textureWarning})");

        // 增量报警（跳过第一轮）
        if (checkRound > 1 && texDelta > singleRoundGrowthWarning)
            Debug.LogWarning($"[MemoryMonitor] ⚠️ Texture2D 本轮增长 {texDelta} 个, 可能泄漏");

        if (checkRound > 1 && goDelta > 20)
            Debug.LogWarning($"[MemoryMonitor] ⚠️ GameObject 本轮增长 {goDelta} 个, 可能泄漏");

        // 定期日志（可接入远程日志服务器）
        Debug.Log($"[MemoryMonitor] R{checkRound} | " +
                  $"Tex:{tex}(+{texDelta}) GO:{go}(+{goDelta}) " +
                  $"Heap:{heap / 1024 / 1024:F1}MB");

        lastTextureCount = tex;
        lastGameObjectCount = go;
    }

    private static int CountAssets<T>() where T : Object =>
        Resources.FindObjectsOfTypeAll<T>().Length;

    private static int CountObjects<T>() where T : Object =>
        FindObjectsOfType<T>().Length;
}
```

### 6.5 代码级模式扫描 — 不运行游戏就能检测

**原理**：扫描项目所有 `.cs` 文件，匹配常见泄漏代码模式。零运行成本，可集成到 CI。

```csharp
/// <summary>
/// 代码级泄漏模式扫描器（Editor Only）
/// 不需要运行游戏，静态扫描脚本中的潜在泄漏模式
/// </summary>
#if UNITY_EDITOR
public static class LeakPatternScanner
{
    [MenuItem("Tools/Memory/Scan Leak Patterns")]
    public static void Scan()
    {
        var issues = new List<string>();
        var scripts = AssetDatabase.FindAssets("t:Script");

        foreach (var guid in scripts)
        {
            var path = AssetDatabase.GUIDToAssetPath(guid);
            var code = File.ReadAllText(path);

            ScanEventSubscription(code, path, issues);
            ScanStaticCollection(code, path, issues);
            ScanCoroutineLeak(code, path, issues);
            ScanResourcesLoad(code, path, issues);
            ScanDontDestroy(code, path, issues);
        }

        ReportResults(issues);
    }

    /// <summary>
    /// 检测: += 明显多于 -= （事件订阅未取消）
    /// </summary>
    private static void ScanEventSubscription(string code, string path, List<string> issues)
    {
        if (!code.Contains("OnEnable")) return;

        var subscribe = CountOccurrences(code, "+=");
        var unsubscribe = CountOccurrences(code, "-=");

        if (subscribe > unsubscribe + 1)
        {
            issues.Add($"[事件泄漏] {path}: += {subscribe}次 vs -= {unsubscribe}次");
        }
    }

    /// <summary>
    /// 检测: static List/Dictionary 无 Clear/Remove
    /// </summary>
    private static void ScanStaticCollection(string code, string path, List<string> issues)
    {
        if (!code.Contains("static")) return;
        if (!(code.Contains("List<") || code.Contains("Dictionary<"))) return;

        if (!code.Contains(".Clear()") && !code.Contains(".Remove("))
        {
            issues.Add($"[静态集合] {path}: static 集合无 Clear/Remove");
        }
    }

    /// <summary>
    /// 检测: StartCoroutine 无对应 StopCoroutine
    /// </summary>
    private static void ScanCoroutineLeak(string code, string path, List<string> issues)
    {
        if (!code.Contains("StartCoroutine")) return;

        if (!code.Contains("StopCoroutine") && !code.Contains("StopAllCoroutines"))
        {
            issues.Add($"[协程泄漏] {path}: 有 StartCoroutine 无 Stop");
        }
    }

    /// <summary>
    /// 检测: Resources.Load 无 Resources.Unload
    /// </summary>
    private static void ScanResourcesLoad(string code, string path, List<string> issues)
    {
        if (!code.Contains("Resources.Load")) return;

        if (!code.Contains("Resources.Unload"))
        {
            issues.Add($"[资源泄漏] {path}: 有 Resources.Load 无 Resources.Unload");
        }
    }

    /// <summary>
    /// 检测: DontDestroyOnLoad 无场景切换清理
    /// </summary>
    private static void ScanDontDestroy(string code, string path, List<string> issues)
    {
        if (!code.Contains("DontDestroyOnLoad")) return;

        if (!code.Contains("Destroy") && !code.Contains("sceneUnloaded"))
        {
            issues.Add($"[常驻对象] {path}: DontDestroyOnLoad 无清理逻辑");
        }
    }

    private static int CountOccurrences(string text, string pattern)
    {
        int count = 0, idx = 0;
        while ((idx = text.IndexOf(pattern, idx)) != -1)
        {
            count++;
            idx += pattern.Length;
        }
        return count;
    }

    private static void ReportResults(List<string> issues)
    {
        if (issues.Count == 0)
        {
            Debug.Log("[LeakScanner] ✅ 未发现明显的泄漏模式");
            return;
        }

        Debug.LogWarning($"[LeakScanner] 发现 {issues.Count} 个潜在风险：\n");
        foreach (var issue in issues)
            Debug.LogWarning($"  {issue}");
    }
}
#endif
```

### 6.6 自动化测试集成 — CI 门禁

**原理**：用 Unity Test Framework 写泄漏测试，每次构建自动跑，泄漏超过阈值则构建失败。

```csharp
/// <summary>
/// 自动化内存泄漏测试（Unity Test Framework）
/// 用法: Unity 命令行 -runTests -testPlatform PlayMode
/// </summary>
public class MemoryLeakTests
{
    [UnityTest]
    public IEnumerator SceneSwitch_NoTextureLeak()
    {
        // 1. 进入主菜单，记录基线
        yield return SceneManager.LoadSceneAsync("MainMenu");
        yield return WaitForGC();
        var baselineTex = CountAssets<Texture2D>();

        // 2. 循环切换场景 5 次
        for (int i = 0; i < 5; i++)
        {
            yield return SceneManager.LoadSceneAsync("Level_01");
            yield return new WaitForSeconds(1f);
            yield return SceneManager.LoadSceneAsync("MainMenu");

        var finalTex = CountAssets<Texture2D>();

        // 增长不超过 5 个 = 通过（允许少量缓存）
        Assert.LessOrEqual(
            finalTex, baselineTex + 5,
            $"Texture2D 泄漏: {baselineTex} → {finalTex} (5次场景切换后)");
    }

    [UnityTest]
    public IEnumerator SceneSwitch_NoGameObjectLeak()
    {
        yield return SceneManager.LoadSceneAsync("MainMenu");
        yield return WaitForGC();
        var baselineGO = CountObjects<GameObject>();

        for (int i = 0; i < 5; i++)
        {
            yield return SceneManager.LoadSceneAsync("Level_01");
            yield return SceneManager.LoadSceneAsync("MainMenu");
        }

        yield return WaitForGC();
        var finalGO = CountObjects<GameObject>();

        Assert.LessOrEqual(
            finalGO, baselineGO + 20,
            $"GameObject 泄漏: {baselineGO} → {finalGO}");
    }

    [UnityTest]
    public IEnumerator SceneSwitch_NoManagedHeapGrowth()
    {
        yield return SceneManager.LoadSceneAsync("MainMenu");
        yield return WaitForGC();
        var baselineHeap = GC.GetTotalMemory(true);

        for (int i = 0; i < 5; i++)
        {
            yield return SceneManager.LoadSceneAsync("Level_01");
            yield return SceneManager.LoadSceneAsync("MainMenu");
        }

        yield return WaitForGC();
        var finalHeap = GC.GetTotalMemory(true);

        // 托管堆增长不超过 10MB
        Assert.LessOrEqual(
            finalHeap, baselineHeap + 10 * 1024 * 1024,
            $"托管堆增长超过 10MB: {baselineHeap / 1024 / 1024:F1}MB → {finalHeap / 1024 / 1024:F1}MB");
    }

    private static IEnumerator WaitForGC()
    {
        GC.Collect();
        GC.WaitForPendingFinalizers();
        GC.Collect();
        Resources.UnloadUnusedAssets();
        yield return new WaitForSeconds(2f);
    }

    private static int CountAssets<T>() where T : Object =>
        Resources.FindObjectsOfTypeAll<T>().Length;

    private static int CountObjects<T>() where T : Object =>
        Object.FindObjectsOfType<T>().Length;
}
```

### 6.7 Memory Profiler API — 自动拍快照

在关键节点自动拍快照，省去手动操作：

```csharp
#if UNITY_EDITOR
using Unity.MemoryProfilerExtension;

/// <summary>
/// 自动快照工具
/// 在场景切换时自动 GC + 拍快照，事后在编辑器中对比
/// </summary>
public class AutoMemorySnapshot : MonoBehaviour
{
    [SerializeField] private string sessionName = "LeakTest";
    private int snapshotIndex;

    private void OnEnable()
    {
        SceneManager.sceneUnloaded += OnSceneUnloaded;
    }

    private void OnSceneUnloaded(Scene scene)
    {
        StartCoroutine(DelayedSnapshot($"After_{scene.name}_{snapshotIndex++}"));
    }

    private IEnumerator DelayedSnapshot(string label)
    {
        GC.Collect();
        GC.WaitForPendingFinalizers();
        GC.Collect();
        yield return new WaitForSeconds(2f);

        MemoryProfiler.TakeSnapshot(
            $"{sessionName}_{label}",
            success => Debug.Log($"[Memory] 快照已保存: {label}"));
    }

    private void OnDisable()
    {
        SceneManager.sceneUnloaded -= OnSceneUnloaded;
    }
}
#endif
```

> **注意**：Memory Profiler API 只能自动拍快照和保存，**无法编程读取快照内容做自动 diff**。diff 仍需人工在编辑器中操作。

### 6.8 朴素方案：日志埋点（最简但有效）

不想写复杂追踪系统时，在资源加载/卸载点加计数日志：

```csharp
public class ResourceManager : MonoBehaviour
{
    private static int loadCount;
    private static int unloadCount;

    public T LoadAsset<T>(string path) where T : Object
    {
        loadCount++;
        Debug.Log($"[Resource] Load #{loadCount}: {path}");
        return Resources.Load<T>(path);
    }

    public void UnloadAsset(string path)
    {
        unloadCount++;
        Debug.Log($"[Resource] Unload #{unloadCount}: {path}");
    }

    // OnGUI 显示实时差额
    private void OnGUI()
    {
        GUI.color = loadCount - unloadCount > 10 ? Color.red : Color.white;
        GUI.Label(new Rect(10, 10, 400, 20),
            $"Load: {loadCount} | Unload: {unloadCount} | 差额: {loadCount - unloadCount}");
    }
}
```

差额持续增长不收敛 = 泄漏。再去翻日志找哪些资源只 Load 没 Unload。

### 6.9 方案对比与推荐组合

| 方案 | 成本 | 自动化程度 | 能定位到 | 适用阶段 |
|------|------|-----------|---------|----------|
| **二分隔离** | 低 | 半自动 | 哪个系统泄漏 | 开发期排查 |
| **分配追踪** | 中 | 全自动 | 哪行代码泄漏 | 开发期排查 |
| **运行时监控** | 低 | 全自动 | 资源数量异常 | 开发 + 线上 |
| **代码扫描** | 中 | 全自动 | 哪个文件有风险 | 开发 + CI |
| **自动化测试** | 高 | 全自动 | 场景切换是否泄漏 | CI + 发布门禁 |
| **快照 API** | 低 | 半自动 | 快照自动保存 | 开发期排查 |
| **日志埋点** | 极低 | 手动 | Load/Unload 差额 | 快速验证 |

**推荐组合**：

```
日常开发: 运行时监控 + 代码扫描          ← 自动报警，零成本
深入排查: 二分隔离 → 分配追踪 → 引用链   ← 三层定位法
发布门禁: 自动化测试 (CI)               ← 泄漏超阈值构建失败
线上监控: 运行时监控日志上报             ← 线上内存异常预警
```
